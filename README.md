# BMI 身體質量指數計算器 (BMI Calculator)

這是一個使用 Python 編寫的簡易 BMI（Body Mass Index，身體質量指數）計算小工具，能根據使用者輸入的身高與體重，快速計算出 BMI 並對照台灣衛生福利部標準判斷體位。

---

## 📌 功能特色

- **輸入直覺**：輸入身高（公分 cm）與體重（公斤 kg），程式自動換算為公尺計算。
- **防呆設計**：若輸入非數字或小於等於 0 的不合邏輯數值，會跳出友善提示。
- **衛福部體位標準**：提供精確的體位判定結果。

---

## 📐 BMI 計算公式

$$\text{BMI} = \frac{\text{體重 (kg)}}{[\text{身高 (m)}]^2}$$

### 台灣衛生福利部體位判定標準：

| BMI 範圍 | 體位分類 |
| :--- | :--- |
| **BMI < 18.5** | 體重過輕 |
| **18.5 ≤ BMI < 24.0** | 正常範圍（健康體位） |
| **24.0 ≤ BMI < 27.0** | 體重過重 |
| **27.0 ≤ BMI < 30.0** | 輕度肥胖 |
| **30.0 ≤ BMI < 35.0** | 中度肥胖 |
| **BMI ≥ 35.0** | 重度肥胖 |

---

## 🚀 如何執行

請確保您的電腦已安裝 Python 3，在終端機（PowerShell / 終端機）中執行以下指令：

```bash
python bmi_calculator.py
```
